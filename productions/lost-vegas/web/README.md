# lost vegas — web restoration

A JavaScript/WebGL restoration of **"lost vegas" by threestate**
(64k intro, 3rd place @ Ambience 2000, NL, March 2000) — reconstructed from
the original binary as part of Dutch demoscene immaterial-heritage
preservation.

- **Live: https://jasper2-0.github.io/lost-vegas-webgl/**
- Original: [Pouet](https://www.pouet.net/prod.php?which=93)

## Running

Serve this directory with any static web server and open `index.html`.
No build step, no WASM, no external dependencies at runtime.

URL options:

| param | effect |
|---|---|
| *(none)* | remastered: 4× textures with mipmaps, tessellated geometry, framebuffer follows the window, 16-bit soundtrack with richer partials |
| `?quality=original` | authentic: fixed 640×480, 1× textures, original tessellation, original softsynth |
| `?tess=N` | geometry tessellation multiplier (default 4; forced to 1 by `quality=original`) |
| `?audio=original` / `?audio=16bit` | choose the soundtrack rendering independently of `quality` |
| `?pos=N` / `?pos=0xN` | boot paused at a song position, no audio (for inspection) |
| `?debug` | the same, from the start |

The picture is always 4:3, letterboxed into the window — the original ran a
fixed 640×480 and nothing is cropped or stretched to fill a widescreen frame.

## Restoration notes

- **Engine.** Direct3D 7 immediate mode is reimplemented as `js/minid3d7.js`,
  a shim over WebGL2 that keeps D3D's conventions rather than translating them
  away: left-handed coordinates, row-major matrices, `[0,1]` depth, clockwise
  front faces, `D3DCOLOR` in BGRA. The intro uses exactly two vertex formats
  (`0x242` transformed-by-us, `0x244` pre-transformed) and two primitive types,
  with lighting disabled — all shading is baked into vertex colours and
  textures.
- **Timeline.** There is no script table. The original sequences itself with a
  ladder of `while (musicpos < T)` blocks, so the port plays the module live
  and the timeline is locked to the music by construction — no sync map and no
  latency calibration. The *audible* song position is recovered by tagging each
  rendered audio buffer with the position it will sound at, because the
  player's own position runs ahead of the speakers by the buffer depth.
- **Textures.** The credited "DR design generator" is not a procedural
  generator: it is a hand-written **MPEG-1 I-frame decoder**, used as a texture
  compressor in 2000. stevie drew the artwork, encoded each image as a
  single-frame elementary stream and embedded it. The port decodes the same
  blobs to within a mean absolute error of 0.04/255 of ffmpeg, and keeps the
  original's full-range JFIF colour coefficients rather than BT.601 — which is
  "wrong", and therefore preserved.
- **Music.** An MXM module driving a cosine-additive procedural softsynth, both
  reconstructed from the binary.
- **Type.** A 2-bit alpha atlas with a proportional width table and a *vertical*
  kern table. Characters outside `a–z0–9#+` over-read that table; `*` lands on
  zeros and renders as an invisible zero-width glyph, which is how
  `threestate**in***lost***vegas**` gets its spacing. Bug, feature or typing
  convenience, it is part of the work, so it is ported.
- **The remaster layer is strictly additive.** `?quality=original` is the
  faithful reconstruction and reads byte-identical 1× assets; the remastered
  assets are regenerated by the *ported* generators at higher resolution, never
  upscaled. See `assets/remaster/README.md` for what each one does. Known
  deviations are documented in the source headers.

## Provenance & reuse

Nothing here is threestate's source. It is a reconstruction from the shipped
2000 binary — see `METHOD.md` for how, and for what was inferred rather than
proven.

- `js/` is reconstruction code written for this port, **except `js/xm.js`**,
  whose replay behaviour is ported from Olav Sørensen's `ft2-clone` and carries
  its BSD-3-Clause notice. Keep that notice if you reuse the file.
- `assets/` is **derived from the original executable**: the module, the font
  atlas and the DR-design images are threestate's work, decoded and re-baked
  here, not authored here. Everything in `assets/remaster/` is the same data
  regenerated at higher resolution by the ported generators — no new artwork.
- The intro itself — design, code, music, artwork — remains the work of
  **threestate**. It is reproduced for preservation. Questions about reusing
  *their* work go to them, not to this repository.

There is no build step: what you see in `js/` is what runs.
